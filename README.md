# Biniam Birhanu Portfolio

A React portfolio website built with Vite and Tailwind CSS.

## Stack

- React
- Vite
- Tailwind CSS
- EmailJS for the contact form

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Build for production:

   ```bash
   npm run build
   ```

## Notes

- The portfolio uses Tailwind utility classes for styling.
- Dark mode is handled with Tailwind's `dark` class strategy.
- The contact form uses EmailJS credentials already configured in the app.
- Old duplicate asset folders and generated build output were removed.
- The featured projects section remains removed.
